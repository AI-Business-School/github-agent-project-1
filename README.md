# Simple Landing Page

A clean, responsive landing page template built with HTML5 and CSS3.

## Features

- Responsive design that works on all devices
- Modern layout with hero section
- Custom SVG logos in the "Trusted by" section
- Customer testimonials
- Contact form
- Clean, maintainable CSS

## Sections

- Header with navigation
- Hero section with call-to-action buttons
- Features highlights
- Client/company logos
- Customer testimonials
- Call-to-action section
- Contact information and form
- Footer with social links

## Usage

Simply download or clone this repository and modify the HTML and CSS files to suit your needs.

## GitHub Codespaces

This project is configured to work with GitHub Codespaces. To start development in a cloud-based environment:

1. Click on the "Code" button in the GitHub repository
2. Select the "Codespaces" tab
3. Click "Create codespace on main"

The development environment will be set up automatically with:
- Live Server extension for previewing the website
- GitHub Copilot for AI-assisted coding
- Prettier for code formatting

Once the Codespace is ready, you can:
- Use Live Server to preview the website (click "Go Live" in the status bar)
- Edit files and see changes in real-time
- Use GitHub Copilot to help with coding tasks
