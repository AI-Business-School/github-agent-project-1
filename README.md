# Simple Landing Page

A clean, responsive landing page template built with HTML5 and CSS3.

## Features

- Responsive design that works on all devices
- Modern layout with hero section
- Custom SVG logos in the "Trusted by" section
- Customer testimonials
- Contact form
- Clean, maintainable CSS

## Sections

- Header with navigation
- Hero section with call-to-action buttons
- Features highlights
- Client/company logos
- Customer testimonials
- Call-to-action section
- Contact information and form
- Footer with social links

## Usage

Simply download or clone this repository and modify the HTML and CSS files to suit your needs.
